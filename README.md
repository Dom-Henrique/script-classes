💻 Script Language for Web Classes – Federal Institute of Paraíba ☄️

Taught by Professor John Lennon, Script Language for Web is a course focused on JavaScript and its applications in web development.

Since I already have some experience with JavaScript through the CWI program, I believe this course will be a great opportunity to deepen my knowledge, improve my programming skills, and explore new possibilities in software development.

📚 How is this repository organized?

Each class has its own folder, usually containing exercises and homework assignments to put the concepts learned in class into practice.

Here's a quick overview of the repository structure:

Folder	Contents
📁 class-2	Free-theme landing page, click counter, and numbers mean calculator
📁 class-3	Input/output exercises
📁 class-4	Conditionals and loops exercises
📁 class-6	Functions, strings, arrays, objects and JSON
📁 class-7	DOM

More classes and exercises will be added as the course progresses!

🚀 How to clone this repository?

First, open a terminal of your choice and run the following command:

Using HTTPS:

bash
git clone https://github.com/Dom-Henrique/script-classes.git


Using SSH (recommended if you already have an SSH key configured):

bash
git clone git@github.com:Dom-Henrique/script-classes.git


Once the cloning process is complete, navigate into the project directory:

bash
cd script-classes


And voilà! 🎉 You're ready to explore the exercises and follow along with my learning journey.
